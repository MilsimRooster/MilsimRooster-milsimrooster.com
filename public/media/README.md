# Media Folder

Place website media here.

Use lowercase, web-safe filenames when possible, for example:

- `portrait-session-01.jpg`
- `field-demo-01.mp4`
- `command-center-thumb.jpg`

Reference files from React with paths beginning at `/media/`, such as:

```jsx
<img src="/media/photography/portraits/portrait-session-01.jpg" alt="Portrait session" />
```
