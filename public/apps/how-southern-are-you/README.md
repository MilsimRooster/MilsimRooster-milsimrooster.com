# How Southern Are You?

A static Milsim Rooster quiz app published at:

```text
/apps/how-southern-are-you/
```

Version 1 is intentionally backend-free. It randomizes a 20-question run from 150 weighted questions, then builds a result card from separate title, badge, observation, warning, caption, and regional-note pools.

## Files

- `index.html` - page shell and SEO metadata
- `style.css` - mobile-first visual styling
- `app.js` - quiz flow, scoring, sharing, and image download
- `questions.js` - scored question pool
- `results.js` - result-generation content pools

## Content Guardrails

Keep jokes warm and recognizable. Good targets are food habits, church potlucks, weather, manners, backroads, family quirks, home repair, and sweet tea. Avoid hateful, political, racist, classist, or copied social-media jokes.
